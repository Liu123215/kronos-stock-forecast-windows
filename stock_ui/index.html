1
确认股票与行情截至日期

盘中使用上一已收盘交易日；北京时间 15:15 后尝试纳入当日行情。

2
区分完整历史和实际输入

5000 根可以浏览、导出。Small / Base 每次最多输入 512 根，Mini 最多 2048 根。

3
保留原始数据和预测结果

分别导出全部历史、实际输入和预测 CSV，便于之后对照真实走势。

常见疑问

为什么换了日线数量，预测方向也变了？

历史窗口改变，会同时改变上下文和标准化统计值。当前程序固定随机种子 42，使用 3 条采样路径取均值；相同结果的重复出现不等于独立验证。窗口之间方向分歧，说明结果对设置敏感。

为什么没有取到完整的 5000 根？

历史根数取决于上市时间、无成交日和数据源覆盖。页面会显示实际数量与日期范围，程序不会补造历史。预测输入不足时会明确报错。

第一次下载模型较慢怎么办？

保持启动窗口打开。官方站点不可达时，可以关闭窗口并使用随包的第三方镜像入口。两个入口都校验固定官方版本的文件大小和 SHA256，有效缓存会复用。

可以直接按预测进行买卖吗？

本工具用于学习、研究和辅助分析，不保证预测准确或收益。模型没有直接接入新闻和基本面，软件也不连接券商或执行买卖。
